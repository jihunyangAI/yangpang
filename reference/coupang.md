## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스 형태 | 종합 온라인 커머스 (직매입 + 오픈마켓 혼합) |
| 핵심 가치 | 빠른 배송(로켓배송·새벽배송·당일배송), 최저가, 간편결제, 무료 반품 |
| 판매 모델 | 쿠팡 내부 구분은 1P/2P/3P. ① **1P 직매입(로켓배송)**: 쿠팡이 매입하고 판매가·재고도 쿠팡이 정함 (일반과세자만 공급 가능) ② **2P 로켓그로스**: 판매자가 쿠팡 물류센터에 입고하면 쿠팡이 풀필먼트(보관·포장·배송·CS·반품)를 대행, 조건 충족 시 '판매자로켓' 배지 ③ **3P 마켓플레이스**: 쿠팡 윙(Wing)으로 입점, 판매자가 직접 배송 |
| 수익원 | 상품 판매 마진, 판매 수수료, 물류 수수료(로켓그로스), 광고, 멤버십(로켓와우) 구독료, 쿠팡이츠/플레이 등 |
| 채널 | PC 웹, 모바일 웹, iOS/Android 앱 (앱 비중이 압도적) |
| 핵심 차별점 | 자체 물류망(풀필먼트센터·캠프), 자체 배송 인력(쿠팡친구), 멤버십 기반 락인, "아이템 위너" 구조 |

## 3. 공통 레이아웃

### 3.1 PC 헤더
| 영역 | 구성요소 |
|---|---|
| 최상단 바 | 즐겨찾기, 입점신청, 로그인/회원가입, 고객센터 |
| 메인 헤더 | 로고(홈 이동), **카테고리 버튼(햄버거)**, **통합 검색창**(카테고리 셀렉트 + 키워드 + 검색 버튼), 마이쿠팡, 장바구니(수량 배지) |
| 서브 내비 | 로켓배송, 로켓프레시, 골드박스, 쿠팡비즈, 이벤트/쿠폰, 판매자특가, 로켓직구, 반품마켓 등 바로가기 |
| 카테고리 플라이아웃 | 대분류 hover 시 중·소분류 메가메뉴 노출 |

### 3.2 모바일 앱 공통
- 상단: 검색창(고정), 장바구니 아이콘, 알림
- **하단 탭바**: 홈 / 카테고리 / 검색(또는 와우·쿠팡플레이 바로가기) / 마이쿠팡 / 장바구니 (버전에 따라 변동)
- 플로팅 요소: 맨 위로 버튼, 최근 본 상품

### 3.3 푸터
- 회사소개, IR, 채용, 입점/제휴 문의, 광고 안내
- 이용약관, **개인정보처리방침**(강조), 청소년보호정책, 위치기반서비스 약관
- 사업자 정보(상호, 대표, 사업자등록번호, 통신판매업 신고번호, 주소, 호스팅 제공자)
- 고객센터 전화·운영시간, 전자금융거래 분쟁 처리 안내
- 구매안전서비스(에스크로) 안내, 인증마크
- 오픈마켓 고지문: "쿠팡은 통신판매중개자로서 판매자 상품의 거래 당사자가 아닙니다"

### 3.4 PC 우측 퀵메뉴(윙 배너)
- 최근 본 상품 썸네일, 장바구니 바로가기, 맨 위로

## 4. 메인(홈) 페이지

위에서 아래 순서의 대표적 섹션 구성:

| # | 섹션 | 설명 |
|---|---|---|
| 1 | 메인 배너 캐러셀 | 대형 프로모션 배너, 자동 슬라이드, 인디케이터 |
| 2 | 바로가기 아이콘 그리드 | 로켓프레시, 로켓직구, 골드박스, 쿠팡이츠, 쿠팡플레이, 트래블, 선물하기, 와우 전용 등 원형/사각 아이콘 |
| 3 | 오늘의 발견 / 개인화 추천 | "OO님을 위한 추천", 최근 본 상품 기반 |
| 4 | **골드박스(타임딜)** | 매일 오전 7시 갱신되는 한정 특가, 남은 시간 카운트다운 |
| 5 | 와우 회원 전용 특가 | 와우 회원 할인가 노출 |
| 6 | 카테고리별 추천 상품 | 탭 형태 카테고리 + 상품 캐러셀 |
| 7 | 자주 산 상품 / 재구매 | 로그인 사용자 대상 |
| 8 | 기획전/브랜드 배너 | 시즌 기획전, 브랜드위크 |
| 9 | 로켓프레시 신선 섹션 | 오늘 시키면 내일 새벽 도착 |
| 10 | 인기 검색어/랭킹 | 실시간 많이 산 상품 |
| 11 | 무한 스크롤 추천 피드 | 모바일 앱: 하단으로 개인화 상품 피드 지속 |

**상품 카드 공통 구성요소** (모든 리스트에서 재사용)
- 썸네일 이미지 (품절 시 dim 처리)
- 상품명 (2줄 말줄임)
- 할인율(%) + 정가(취소선) + **판매가**
- 와우 할인가 / 쿠폰 적용가 / 카드 할인가 표시
- 단위 가격 (예: 100g당 1,230원)
- 배송 배지: `로켓배송`, `로켓와우`, `판매자로켓`, `로켓프레시`, `로켓직구`, `무료배송`
- **도착 예정일**: "내일(목) 도착 보장", "내일 새벽 도착 보장"
- 별점 + 리뷰 수 (예: ★★★★☆ (12,345))
- 적립 정보 (쿠팡캐시 최대 n원 적립)
- 품절임박 / 한정수량 / 광고(AD) 라벨

## 5. 카테고리 / 탐색

### 5.1 카테고리 체계 (대분류 예시)
패션의류/잡화 · 뷰티 · 출산/유아동 · 식품 · 주방용품 · 생활용품 · 홈인테리어 · 가전디지털 · 스포츠/레저 · 자동차용품 · 도서/음반/DVD · 완구/취미 · 문구/오피스 · 반려동물용품 · 헬스/건강식품 · 여행/티켓

- **4~5단계 트리** 구조 (대 > 중 > 소 > 세)
- 한 상품은 하나의 "표준 카테고리"에 속하고, 기획전·전시 카테고리에는 다중 노출 가능 (표준 카테고리 ≠ 전시 카테고리)

### 5.2 카테고리 페이지 구성
- 카테고리 경로(브레드크럼)
- 하위 카테고리 칩/아이콘
- 카테고리 전용 배너·베스트 상품
- 상품 목록 (7장 참고)

## 6. 검색

### 6.1 검색 입력
- **자동완성**: 입력 중 키워드 제안, 카테고리 제안, 브랜드 제안
- **최근 검색어**: 개별 삭제 / 전체 삭제 / 자동저장 끄기
- **인기 검색어 / 급상승 검색어**
- 오타 교정 ("~로 검색한 결과입니다. ~로 검색하시겠습니까?")
- 동의어·영한 변환 처리 (예: "ㅇㅍ" → "애플", "nike" → "나이키")
- 모바일: 음성 검색, **이미지(카메라) 검색**, 바코드 검색

### 6.2 검색 결과
- 연관 검색어 칩
- 카테고리 추천 (검색어가 속한 카테고리)
- 광고 상품(AD) 상단·중간 혼합 노출
- 필터·정렬 (7장과 동일)
- 결과 없음 화면: 추천 키워드, 인기 상품

## 7. 상품 목록(리스트) 페이지

### 7.1 정렬 옵션
쿠팡 랭킹순(기본) · 낮은가격순 · 높은가격순 · 판매량순 · 최신순 · 리뷰 많은순(평점순)

### 7.2 필터
| 필터 | 내용 |
|---|---|
| 배송 | 로켓배송, 로켓와우, 판매자로켓, 로켓프레시, 로켓직구, 무료배송, 오늘출발 |
| 카테고리 | 하위 카테고리 |
| 브랜드 | 다중 선택, 검색 |
| 가격대 | 슬라이더/구간 + 직접 입력 |
| 별점 | 4점 이상 등 |
| 상품 속성 | 카테고리별 동적 속성 (용량, 색상, 사이즈, 소재, 성별, 연령 등) |
| 혜택 | 쿠폰 할인, 카드 할인, 와우 할인 |
| 기타 | 해외구매 제외, 품절 제외 |

### 7.3 보기 방식
- 리스트형 / 갤러리형(그리드) 전환
- 페이지당 개수 (PC: 36/48/60/72), 페이지네이션 (PC) / 무한스크롤 (앱)

1. **상품상세**: 판매자 상세 이미지/HTML, 필수 표기 정보(상품정보제공고시: 제조사, 원산지, 품질보증기준, A/S 등), KC 인증 정보
2. **상품평(리뷰)**: 17장 참고
3. **상품문의**: Q&A
4. **배송/교환/반품 안내**: 배송 정책, 반품비, 반품 불가 사유, 판매자 정보(상호, 대표, 사업장 소재지, 연락처, 통신판매업번호)

### 8.3 부가 영역
- 함께 비교하면 좋을 상품 / 다른 고객이 함께 본 상품 / 함께 구매한 상품
- 같은 브랜드 상품
- 광고 상품 캐러셀
- 하단 고정 구매바(스크롤 시)

### 8.4 아이템 위너(Item Winner) 구조
- 동일 상품(같은 바코드·모델)은 **하나의 상품 페이지로 통합**되고, 여러 판매자가 그 아래 "판매자 오퍼"로 등록됨
- 가격·배송·판매자 평가 등을 종합해 1개 오퍼가 **대표(위너)** 로 노출, 나머지는 "다른 판매자 보기"
- 리뷰·대표 이미지는 상품 단위로 공유 → 개발 시 **상품(Product) / 판매 오퍼(Vendor Item)** 를 분리 설계해야 함

- 실시간 배송 추적 (출고 → 캠프 도착 → 배송 출발 → 배송 완료)
- 배송 완료 사진, 배송 완료 알림
- 도서산간 추가 배송비, 제주 배송
- 배송 지연 시 보상(쿠팡캐시) 정책

|---|---|
| 즉시할인 | 판매가에 반영된 할인 |
| 와우 할인 | 와우 회원 전용가 |
| 상품 쿠폰 | 특정 상품/판매자/카테고리 쿠폰, 다운로드형 |
| 장바구니 쿠폰 | 주문 전체 금액 대상 |
| 카드 할인 | 결제 수단 연동 |
| 쿠팡캐시 적립 | 쿠페이 결제 시, 리뷰 작성 시, 이벤트 |
| 쿠팡캐시 사용 | 1원 단위 사용, 유효기간 존재 |

**할인 적용 순서**(구현 참고): 판매가 → 즉시할인/와우가 → 상품쿠폰 → 장바구니쿠폰 → 쿠팡캐시 → 결제수단 할인. 부분 취소 시 쿠폰·캐시 안분(按分) 로직 필요.

## 16. 취소·반품·교환·환불

| 구분 | 조건/흐름 |
|---|---|
| **주문 취소** | 결제완료~상품준비중: 즉시 취소 / 출고 이후: 반품으로 전환 |
| **반품** | 수령 후 일정 기간(일반 7일, 로켓와우 30일 무료반품 등) 신청 → 사유 선택(단순변심/상품불량/오배송/파손) → 회수 방법(문 앞 회수, 편의점 반품) → 회수 → 검수 → 환불 |
| **교환** | 동일 옵션 교환 / 다른 옵션 교환(가능 시) → 회수 + 새 상품 발송 |
| **환불** | 원결제 수단 환불, 쿠팡캐시 즉시 환불 선택 가능, 회수 전 선환불(로켓배송 일부) |
| **반품비** | 단순변심: 고객 부담(와우는 로켓배송 무료) / 판매자 귀책: 판매자 부담 |
| **반품 불가** | 사용·훼손, 신선식품, 맞춤 제작, 개봉 시 가치 하락 상품 등 |

- 반품 상품은 검수 후 **반품마켓(리퍼)** 으로 재판매

## 23. 핵심 데이터 모델 (개발 참고)

> 쿠팡형 서비스를 구현할 때 필요한 주요 엔티티(개념 모델). 실제 쿠팡 내부 스키마가 아니라 공개 동작을 기반으로 한 설계안.

```
User (회원)
 ├─ id, email, password_hash, name, phone, birth, grade(일반/와우/비즈), status
 ├─ Address[] (배송지: 수령인, 연락처, 우편번호, 주소, 상세, 출입방법, 요청사항, is_default)
 ├─ PaymentMethod[] (쿠페이 카드/계좌 토큰)
 ├─ Membership (와우: 시작일, 다음결제일, 상태)
 ├─ CashLedger[] (캐시 적립/사용/소멸)
 ├─ UserCoupon[]
 ├─ Wishlist[] / RecentView[] / SearchHistory[]

Category (트리)
 └─ id, parent_id, name, depth, sort, attributes_schema

Product (상품 = 카탈로그 단위)
 ├─ id, category_id, brand_id, name, images[], description_html, notice_info(고시정보)
 ├─ rating_avg, review_count
 └─ Option 축 정의 (색상, 사이즈 …)

Item / SKU (옵션 조합)
 └─ id, product_id, option_values, barcode

VendorItem (판매 오퍼 = 판매자 × SKU)  ← 아이템 위너 대상
 ├─ id, item_id, seller_id, price, list_price, stock
 ├─ delivery_type (ROCKET / ROCKET_FRESH / ROCKET_GROWTH / SELLER / GLOBAL)
 ├─ shipping_fee_policy, return_policy
 └─ is_winner

Seller (판매자) – 쿠팡 직매입도 하나의 seller로 취급
Brand
Cart / CartItem (user_id, vendor_item_id, qty, selected)
Order (주문서)
 ├─ id, user_id, order_no, address_snapshot, total_amount, discount, shipping_fee, cash_used, paid_amount, status, ordered_at
 └─ OrderItem[] (vendor_item_id, 상품정보 스냅샷, qty, unit_price, discount_alloc, status)
Shipment (배송: order_item 묶음, carrier, tracking_no, promised_date, delivered_at, photo_url)
Payment (pg, method, amount, approved_at, status) / Refund
Claim (취소/반품/교환: type, reason, status, pickup_info, refund_amount)
Coupon (type: 상품/장바구니/배송비, discount_type: 정액/정률, 조건, 기간, 발급수량)
Review (order_item_id, rating, survey_answers, content, media[], helpful_count)
Inquiry (product_id, user_id, content, secret, answer)
Promotion / Exhibition (기획전: 배너, 상품 목록, 기간)
TimeDeal (골드박스: vendor_item_id, deal_price, 시작/종료, 수량)
Subscription (정기배송: vendor_item_id, cycle, next_date)
Notification
```

**설계 포인트**
- 주문 시점 **상품·가격·배송지 스냅샷** 저장 (이후 상품 변경과 무관하게 주문 정보 보존)
- 재고는 VendorItem 단위, 주문 시 **재고 선점(예약) → 결제 완료 시 확정 → 실패 시 해제**
- 할인 금액은 OrderItem 단위로 **안분 저장** (부분 취소·환불 계산용)
- 배송 유형별로 주문이 **배송 단위(Shipment)로 분리**됨

## 24. 주문 상태 흐름

```
[주문서 작성]
     │
     ▼
 결제대기(무통장) ──(미입금 기한초과)──▶ 주문취소
     │
     ▼
 결제완료 ──(고객 취소)──▶ 취소완료 ──▶ 환불완료
     │
     ▼
 상품준비중(발주확인) ──(고객 취소 요청 → 판매자 승인)──▶ 취소완료
     │
     ▼
 배송지시/출고 ──▶ 배송중 ──▶ 배송완료
                                  │
                ┌─────────────────┼──────────────────┐
                ▼                 ▼                  ▼
          구매확정(자동/수동)   반품요청            교환요청
                │                 │                  │
           리뷰작성 가능       회수중 → 회수완료     회수 → 재발송
                                  │                  │
                               검수 → 반품완료      교환완료
                                  │
                               환불완료
```
- **구매확정**: 배송완료 후 일정 기간 경과 시 자동 확정 → 판매자 정산 트리거
- 클레임(취소/반품/교환)은 OrderItem 단위로 부분 처리 가능
